# TOEIC 單字 App — UI 設計規格（已選定方向 A：紙本辭典）

> 使用者提供的執行文件摘錄。2026-09-01 起本檔取代舊 DESIGN.md 成為視覺唯一準則。
> 改任何介面前先讀 §1 禁止清單；「感覺不對時，回到 §1 逐條檢查」。

## 1. 禁止清單（不得以任何形式復原）
1. 中點串接的資料列（`答對 0 · 答錯 0 · …`）→ §3.6 三欄式
2. 等寬字當標籤（IPA、1/40、日期）——等寬字只用於需要縱向對齊的數字欄
3. 所有元素共用同一個圓角（A 方向：一律 4px，此條以 A 的規定為準）
4. 每個區塊都包一張卡——卡片只給「可被操作的單一物件」，其餘用分隔線與留白
5. 破壞性操作用填色大按鈕——「刪除此字」改文字連結
6. 純裝飾的色塊或色字（如單字上方黃色的 n）
7. 大寫加寬字距的小標籤（eyebrow）
8. 元素載入時的淡入/滑動動畫——只有回應使用者操作的動畫可保留
9. 按鈕文字尾端加箭頭

## 2. 共用尺度
字級：單字(詳情) 44/700/1.1/-0.02em；單字(題幹) 36/700；畫面標題 22/600；
例句英文 18/400/1.5；中文釋義 17/400/1.6；例句中譯 15/400/1.6；
欄位名 13/500/1.4；數據數字 15/500/1.2；數據標籤 12/400/1.2。
**單字必須是畫面上最大的元素。**
間距階梯：4/8/12/16/24/32/48；畫面左右內距 20；區塊間 32；區塊內 12；欄位名與內容 8。
觸控最小 44×44（視覺可小，熱區補足）。

## 3. 元件規則
- 卡片：只有詳情頁單字本體與測驗選項
- 統計：數字大標籤小、上下排列、不包卡、留白分隔
- Pill：只給同義詞/詞形變化；13px、高 32、內距 12，不得比內文大
- 破壞性操作：卡片底部右側文字連結（13px danger）；收藏＝次要按鈕
- 例句：色條只留第一句，其餘縮排；例句間 16px；中譯縮排
- 單字統計：三欄（數字上標籤下）；盒位＝單字右上角 5 個小方塊
- 記憶熱度 stage 0–6 色階＝全 app 唯一多色處（單元列 4px 色條、單元格子圖）

## 4. 方向 A：紙本辭典（採用）
色票：paper #EFEEE9｜surface #F7F6F2｜ink #16150F｜ink-muted #6B6A61｜
rule #D6D4CB｜accent #1B4D3E｜accent-soft #E3EBE6｜danger #8C2F26｜success #2E6B4C
熱度 0–6：#D6D4CB #B8C4B4 #93AE96 #6E9A7C #4A8663 #2E6B4C #1B4D3E
字體：內容英文 Newsreader；內容中文 Noto Serif TC；介面 Noto Sans TC/系統黑體
圓角一律 4px；不使用陰影（層級靠 1px rule 邊框與留白）

## 6. 逐畫面修正
- 詳情：單字 44px、發音鍵 40px 圓形同基線、刪黃色 n、變化 pill 單行橫滾、
  統計三欄移出卡片貼畫面底、刪除改字連結
- 單元列表：每列 64px（名+細進度軸+已學數）、左 4px 熱度色條、
  上方 32 格格子圖（36×36、8×4、色即 stage、點擊跳單元）
- 今日：上方空白改「未來 7 天複習負載」7 直條（今天 accent）；統計不包卡
- 測驗選擇：32 顆單元 pill 合併一組＋單選/複選切換；收藏/常錯用分隔線
- 單字卷：題幹縮高、單字 36px；選項間距 12px；答錯提示在上、按鈕全寬在下

## 7. 順便修的 bug
1. Header 滾動穿透（不透明背景 + z-index）
2. 同義詞過濾：只留與主要詞性相符、且在 TSL 詞表內的字
3. 英英釋義：按 sense rank 取與 ECDICT 主要詞性相符的義項
